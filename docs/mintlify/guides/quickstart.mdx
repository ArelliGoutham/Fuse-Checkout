# Quickstart

Launch your first checkout session in under 5 minutes.

## Step 1: Create an account

Sign up via the dashboard or API to create your merchant account:

```bash
curl -X POST https://api.offerforge.io/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email": "owner@mystore.in",
    "password": "securepassword123",
    "name": "Store Owner",
    "store_name": "My Store"
  }'
```

This returns a JWT token and creates your merchant with the `owner` role:

```json
{
  "token": "eyJhbG...",
  "user": { "_id": "user_...", "email": "owner@mystore.in", "name": "Store Owner" },
  "merchant": { "_id": "merch_...", "name": "My Store" },
  "role": "owner"
}
```

## Step 2: Create an API key

For programmatic access (checkout integration), create an API key:

```bash
curl -X POST https://api.offerforge.io/api/api-keys \
  -H "Authorization: Bearer eyJhbG..." \
  -H "Content-Type: application/json" \
  -d '{
    "label": "Checkout Integration",
    "scopes": ["offers:read", "checkout", "tracking"]
  }'
```

Save the returned `key` — it's shown only once:

```json
{
  "key": "of_live_a1b2c3d4e5f6...",
  "label": "Checkout Integration",
  "scopes": ["offers:read", "checkout", "tracking"]
}
```

## Step 3: Create an offer

Create a coupon that customers can apply at checkout:

```bash
curl -X POST https://api.offerforge.io/api/offers \
  -H "x-api-key: of_live_a1b2c3d4e5f6..." \
  -H "Content-Type: application/json" \
  -d '{
    "code": "FLAT50",
    "type": "coupon",
    "title": "Flat ₹50 off on orders above ₹500",
    "discount": { "type": "flat", "value": 50, "max_discount": null },
    "validity": {
      "starts_at": "2026-01-01T00:00:00.000Z",
      "ends_at": "2026-12-31T23:59:59.000Z"
    },
    "usage_limits": { "total": null, "per_customer": null },
    "rules": [
      { "rule_type": "min_cart_value", "config": { "min_amount": 500 } }
    ]
  }'
```

## Step 4: Create a checkout session

When a customer is ready to pay, create a checkout session and redirect them to the hosted checkout page:

```bash
curl -X POST https://api.offerforge.io/api/checkout/sessions \
  -H "x-api-key: of_live_a1b2c3d4e5f6..." \
  -H "Content-Type: application/json" \
  -d '{
    "cart": {
      "amount": 8999,
      "items": [
        { "sku_id": "SKU-RS999", "name": "Nike Running Shoes", "price": 8999, "qty": 1, "category": "Footwear", "brand": "Nike" }
      ]
    },
    "redirect_urls": {
      "success": "https://store.in/success",
      "cancel": "https://store.in/cancel"
    }
  }'
```

Response:

```json
{
  "session_id": "sess_abc123...",
  "checkout_url": "https://checkout.offerforge.io/sess_abc123...",
  "expires_at": "2026-07-21T09:00:00.000Z"
}
```

## Step 5: Redirect to checkout

Redirect your customer to `checkout_url`. The hosted checkout page handles everything:

1. **Cart review** — customer sees their items and totals
2. **Apply offers** — customer can enter coupon codes or see auto-applied offers
3. **Enter details** — name, email, phone, shipping address
4. **Select payment** — card (with EMI options via BIN lookup), UPI, or bank transfer
5. **Payment processing** — we process the payment and create an order
6. **Redirect** — customer lands back on your `success` URL with order details

<Note>
  The checkout page is hosted by OfferForge — no frontend code needed. For brand customization, contact us about white-label options.
</Note>

## Step 6: Verify the order

After redirect, verify the order using the order ID returned in the success URL:

```bash
curl https://api.offerforge.io/api/orders/order_123 \
  -H "x-api-key: of_live_a1b2c3d4e5f6..."
```

That's it! You've created an offer, launched a hosted checkout, and the customer completed payment. 🎉

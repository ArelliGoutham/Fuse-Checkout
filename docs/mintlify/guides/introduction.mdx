# Introduction

OfferForge is a hosted checkout platform that sits between your cart and payment. One API call creates a full checkout page with coupon validation, auto-applied offers, EMI calculation, and payment processing — so merchants don't have to build any of it.

<Tip>
  New to OfferForge? Check out the [Quickstart](/guides/quickstart) to launch your first checkout session in 5 minutes.
</Tip>

## What OfferForge does

<AccordionGroup>
  <Accordion title="Hosted Checkout">
    Create a checkout session via API, redirect your customer to a hosted page, and we handle the entire flow — cart review, offer application, customer details, payment selection, and order creation.
  </Accordion>
  <Accordion title="Coupon Management">
    Create flat or percentage discounts with codes like `FLAT50`, `SAVE10`. Set min cart values, max discount caps, validity windows, and per-customer usage limits.
  </Accordion>
  <Accordion title="Auto-Applied Offers">
    Show offers automatically based on cart contents — no code needed. e.g., "10% off Electronics" appears when the cart has electronics items.
  </Accordion>
  <Accordion title="EMI Engine">
    Calculate standard, no-cost, and low-cost EMI using our bank rate database. BIN lookup detects the card bank and shows applicable EMI options with monthly amounts.
  </Accordion>
  <Accordion title="Rule Engine">
    13 composable rule types: min cart value, customer segment, first-time buyer, weekend only, category restriction, product combo, date range, and more.
  </Accordion>
  <Accordion title="Payment Orchestration">
    Plug in any payment gateway via our adapter interface. We process the payment, create the order, and redirect back to your success URL.
  </Accordion>
  <Accordion title="Stacking & Conflict Resolution">
    Merchants define how offers combine. The engine resolves conflicts using priority, exclusive flags, and global stacking policies.
  </Accordion>
  <Accordion title="Analytics">
    Track redemptions, conversions, abandonment. Measure AOV lift and revenue impact per offer. Full funnel from checkout session to payment.
  </Accordion>
  <Accordion title="Team Management">
    Invite team members with role-based access (owner, admin, offer_manager, analytics_viewer). Email-bound invite codes with 7-day expiry.
  </Accordion>
</AccordionGroup>

## What OfferForge is NOT

<Callout type="warning">
  OfferForge is not a lending platform and not a coupon aggregator. We handle checkout, offers, and EMI calculation — we orchestrate payments but don't lend money.
</Callout>

| Not this | Because |
|---|---|
| A lending platform | We calculate EMI but don't lend money |
| A coupon aggregator | We're embedded in checkout, not a standalone site |
| Just an offers API | We're a full checkout provider — offers are one part |

## Architecture

OfferForge is built as a **modular monolith** — a single backend with strict module boundaries. Each module (offers, checkout, products, analytics) is self-contained and communicates through interfaces only.

```
Checkout Flow:
  Cart → Create Session → Hosted Checkout Page
                              ├── Offer Engine (coupons, auto-offers, stacking)
                              ├── EMI Engine (bank rates, BIN lookup, EMI calc)
                              ├── Payment Orchestrator (PG adapter)
                              └── Order Creation + Tracking

OfferEvaluatorRegistry
  ├── CouponEvaluator      (code-based)
  ├── AutoOfferEvaluator   (cart-data-driven)
  ├── BankOfferEvaluator   (v2 — card BIN validation)
  ├── BrandOfferEvaluator  (v2 — brand-subsidized)
  └── EMIOfferEvaluator    (v2 — EMI-based offers)
```

New offer types slot in as new evaluators — no changes to existing code.

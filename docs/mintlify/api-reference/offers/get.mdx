# Get Offer

<Endpoint method="GET" path="/api/offers/:id" />

Retrieve a single offer by its ID. Requires `offers:read` scope (API key) or `offer_manager`+ role (JWT).

## Path Parameters

<ParamField path="id" type="string" required>
The offer ID (e.g., `offer_123456_abc`).
</ParamField>

## Example

```bash
curl -X GET https://api.offerforge.io/api/offers/offer_123456_abc \
  -H "x-api-key: of_live_..." \
  -H "Content-Type: application/json"
```

## Errors

| Status | Code | When |
|---|---|---|
| 404 | `NOT_FOUND` | Offer does not exist |
| 401 | `AUTH_INVALID` | Missing or invalid API key |

# List Offers

<Endpoint method="GET" path="/api/offers" />

Retrieve a paginated list of all offers for your merchant. Requires `offers:read` scope (API key) or `offer_manager`+ role (JWT).

## Query Parameters

<ParamField query="type" type="string">
Filter by offer type: `"coupon"` or `"auto_offer"`. Omit to get all offers.
</ParamField>

<ParamField query="status" type="string">
Filter by status: `"active"`, `"scheduled"`, `"expired"`, or `"draft"`. Omit to get all statuses.
</ParamField>

## Example

```bash
curl -X GET https://api.offerforge.io/api/offers?type=coupon&status=active \
  -H "x-api-key: of_live_..." \
  -H "Content-Type: application/json"
```

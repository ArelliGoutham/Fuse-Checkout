# Get Current User

<Endpoint method="GET" path="/api/auth/me" />

Retrieve information about the currently authenticated user and their merchant account. Requires a valid JWT token.

## Example

```bash
curl -X GET https://api.offerforge.io/api/auth/me \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json"
```

## Response (200)

```json
{
  "user": {
    "_id": "user_123456",
    "email": "owner@mystore.com",
    "name": "John Doe"
  },
  "merchant": {
    "_id": "merch_demo",
    "store_name": "My Store",
    "tier": "starter"
  },
  "role": "owner"
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 401 | `AUTH_REQUIRED` | No JWT token provided |
| 401 | `AUTH_INVALID` | Invalid or expired JWT token |

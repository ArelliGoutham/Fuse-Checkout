# Accept Invite

<Endpoint method="POST" path="/api/auth/accept-invite" />

Accept a team member invitation using the invite code. Creates a new user account linked to the merchant. This endpoint does not require authentication.

## Request Body

<ParamField path="invite_code" type="string" required>
The unique invite code from the invitation link or email.
</ParamField>

<ParamField path="email" type="string" required>
Email address (must match the email the invite was sent to).
</ParamField>

<ParamField path="password" type="string" required>
Password for the new account (minimum 8 characters).
</ParamField>

<ParamField path="name" type="string" required>
Full name of the team member.
</ParamField>

## Example

```bash
curl -X POST https://api.offerforge.io/api/auth/accept-invite \
  -H "Content-Type: application/json" \
  -d '{
    "invite_code": "inv_abc123xyz",
    "email": "team@mystore.com",
    "password": "securePassword123",
    "name": "Jane Smith"
  }'
```

## Response (201)

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "_id": "user_789012",
    "email": "team@mystore.com",
    "name": "Jane Smith"
  },
  "merchant": {
    "_id": "merch_demo",
    "store_name": "My Store",
    "tier": "starter"
  },
  "role": "offer_manager"
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `INVALID_INVITE` | Invite code not found or expired |
| 400 | `EMAIL_MISMATCH` | Email does not match invite |
| 400 | `VALIDATION_ERROR` | Invalid password or missing fields |
| 409 | `DUPLICATE_EMAIL` | Email already registered |

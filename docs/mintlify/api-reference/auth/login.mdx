# Login

<Endpoint method="POST" path="/api/auth/login" />

Authenticate with email and password to receive a JWT token. This endpoint does not require authentication.

## Request Body

<ParamField path="email" type="string" required>
Email address of the merchant account.
</ParamField>

<ParamField path="password" type="string" required>
Password for the account.
</ParamField>

## Example

```bash
curl -X POST https://api.offerforge.io/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "owner@mystore.com",
    "password": "securePassword123"
  }'
```

## Response (200)

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "_id": "user_123456",
    "email": "owner@mystore.com",
    "name": "John Doe"
  },
  "merchant": {
    "_id": "merch_demo",
    "store_name": "My Store",
    "tier": "starter"
  },
  "role": "owner"
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `INVALID_CREDENTIALS` | Email or password incorrect |
| 400 | `VALIDATION_ERROR` | Missing email or password |

# Offer Analytics

<Endpoint method="GET" path="/api/analytics/offers" />

Get detailed analytics for each offer, including redemptions, conversions, and revenue impact. Requires `analytics:read` scope (API key) or `analytics` role (JWT).

## Example

```bash
curl -X GET https://api.offerforge.io/api/analytics/offers \
  -H "x-api-key: of_live_..." \
  -H "Content-Type: application/json"
```

## Response (200)

```json
{
  "offers": [
    {
      "offer_id": "offer_123456_abc",
      "code": "FLAT50",
      "title": "Flat ₹50 off",
      "redemptions": 450,
      "conversions": 320,
      "revenue": 18000
    },
    {
      "offer_id": "offer_789012_def",
      "title": "VIP Early Access",
      "redemptions": 800,
      "conversions": 530,
      "revenue": 27000
    }
  ]
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 401 | `AUTH_INVALID` | Missing or invalid API key |

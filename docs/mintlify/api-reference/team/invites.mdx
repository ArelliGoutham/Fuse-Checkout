# List Invites

<Endpoint method="GET" path="/api/team/invites" />

Retrieve a paginated list of pending team invitations. Requires a valid JWT token.

## Query Parameters

<ParamField query="page" type="number">
Page number (defaults to 1).
</ParamField>

<ParamField query="limit" type="number">
Items per page (defaults to 10).
</ParamField>

<ParamField query="status" type="string">
Filter by status: `"pending"`, `"accepted"`, or `"expired"`. Omit to get all statuses.
</ParamField>

## Example

```bash
curl -X GET https://api.offerforge.io/api/team/invites?page=1&limit=10&status=pending \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json"
```

## Response (200)

```json
{
  "invites": [
    {
      "invite_code": "inv_abc123xyz",
      "email": "team@mystore.com",
      "role": "offer_manager",
      "status": "pending",
      "expires_at": "2026-07-26T16:01:44.539+05:30",
      "created_at": "2026-07-19T16:01:44.539+05:30"
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 10,
  "total_pages": 1
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Invalid query parameters |
| 401 | `AUTH_REQUIRED` | No JWT token provided |

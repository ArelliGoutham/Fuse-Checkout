# Revoke Invite

<Endpoint method="DELETE" path="/api/team/invites/:code" />

Revoke a pending team invitation. This cannot be undone. Requires owner or admin role.

## Path Parameters

<ParamField path="code" type="string" required>
The invite code (e.g., `inv_abc123xyz`).
</ParamField>

## Example

```bash
curl -X DELETE https://api.offerforge.io/api/team/invites/inv_abc123xyz \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json"
```

## Response (200)

```json
{
  "revoked": true
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 404 | `NOT_FOUND` | Invite does not exist |
| 403 | `INSUFFICIENT_PERMISSION` | User is not owner or admin |
| 401 | `AUTH_REQUIRED` | No JWT token provided |

# Invite Team Member

<Endpoint method="POST" path="/api/team/invite" />

Send an invitation to a team member. Requires owner or admin role. The invite will expire after 7 days if not accepted.

## Request Body

<ParamField path="email" type="string" required>
Email address of the team member to invite.
</ParamField>

<ParamField path="role" type="string" required>
Role for the team member: `"offer_manager"`, `"product_manager"`, `"analytics"`, or `"admin"`.
</ParamField>

## Example

```bash
curl -X POST https://api.offerforge.io/api/team/invite \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json" \
  -d '{
    "email": "team@mystore.com",
    "role": "offer_manager"
  }'
```

## Response (201)

```json
{
  "invite_code": "inv_abc123xyz",
  "email": "team@mystore.com",
  "role": "offer_manager",
  "expires_at": "2026-07-26T16:01:44.539+05:30",
  "invite_url": "https://app.offerforge.io/invite/inv_abc123xyz"
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Invalid email or role |
| 403 | `INSUFFICIENT_PERMISSION` | User is not owner or admin |
| 401 | `AUTH_REQUIRED` | No JWT token provided |
| 409 | `DUPLICATE_EMAIL` | User already in team |

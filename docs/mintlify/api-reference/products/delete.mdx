# Delete Product

<Endpoint method="DELETE" path="/api/products/:sku_id" />

Delete a product by its SKU ID. This cannot be undone. Requires `products:write` scope (API key) or `product_manager`+ role (JWT).

## Path Parameters

<ParamField path="sku_id" type="string" required>
The product SKU ID (e.g., `"PROD-001"`).
</ParamField>

## Example

```bash
curl -X DELETE https://api.offerforge.io/api/products/PROD-001 \
  -H "x-api-key: of_live_..." \
  -H "Content-Type: application/json"
```

## Response (200)

```json
{
  "deleted": true
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 404 | `NOT_FOUND` | Product does not exist |
| 401 | `AUTH_INVALID` | Missing or invalid API key |

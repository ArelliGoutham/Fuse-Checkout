# List Products

<Endpoint method="GET" path="/api/products" />

Retrieve a list of all products for your merchant, optionally filtered by category. Requires `products:read` scope (API key) or `product_manager`+ role (JWT).

## Query Parameters

<ParamField query="category" type="string">
Filter products by category (e.g., `"apparel"`, `"electronics"`). Omit to get all products.
</ParamField>

## Example

```bash
curl -X GET https://api.offerforge.io/api/products?category=apparel \
  -H "x-api-key: of_live_..." \
  -H "Content-Type: application/json"
```

## Response (200)

```json
{
  "products": [
    {
      "_id": "prod_123456_abc",
      "merchant_id": "merch_demo",
      "sku_id": "PROD-001",
      "name": "Blue Cotton T-Shirt",
      "category": "apparel",
      "brand": "Nike",
      "created_at": "2026-07-18T10:00:00.000Z",
      "updated_at": "2026-07-18T10:00:00.000Z"
    }
  ]
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Invalid query parameters |
| 401 | `AUTH_INVALID` | Missing or invalid API key |

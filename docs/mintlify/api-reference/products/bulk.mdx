# Bulk Upsert Products

<Endpoint method="POST" path="/api/products/bulk" />

Create or update multiple products at once. Useful for syncing your catalog. Requires `products:write` scope (API key) or `product_manager`+ role (JWT).

## Request Body

<ParamField path="products" type="array" required>
Array of product objects. Each object should have `sku_id` (required), `name` (required), `category`, and `brand`.
</ParamField>

## Example

```bash
curl -X POST https://api.offerforge.io/api/products/bulk \
  -H "x-api-key: of_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "products": [
      {
        "sku_id": "PROD-001",
        "name": "Blue Cotton T-Shirt",
        "category": "apparel",
        "brand": "Nike"
      },
      {
        "sku_id": "PROD-002",
        "name": "iPhone 15 Pro",
        "category": "electronics",
        "brand": "Apple"
      }
    ]
  }'
```

## Response (200)

```json
{
  "upserted": 2
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Invalid request body or product data |
| 401 | `AUTH_INVALID` | Missing or invalid API key |

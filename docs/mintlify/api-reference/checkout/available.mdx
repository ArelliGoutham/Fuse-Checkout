# Get Available Offers

<Endpoint method="POST" path="/api/offers/available" />

Get coupons and auto-offers eligible for a customer's current cart. This endpoint evaluates all active offers against the provided cart and customer context to return only applicable offers. No authentication required for checkout flows.

## Request Body

<ParamField path="cart" type="object" required>
<ParamField path="cart.amount" type="number" required>Total cart value in ₹</ParamField>
<ParamField path="cart.items" type="array" required>Array of cart items with `sku_id` and `quantity`</ParamField>
</ParamField>

<ParamField path="customer" type="object" required>
<ParamField path="customer.customer_id" type="string" required>Unique customer identifier</ParamField>
<ParamField path="customer.segments" type="array">Customer segments (e.g., `["vip", "first_order"]`)</ParamField>
<ParamField path="customer.total_orders" type="number">Total orders placed by customer</ParamField>
<ParamField path="customer.per_customer_used" type="object">Object mapping offer IDs to times used (for limit checking)</ParamField>
</ParamField>

## Example

```bash
curl -X POST https://api.offerforge.io/api/offers/available \
  -H "Content-Type: application/json" \
  -d '{
    "cart": {
      "amount": 1500,
      "items": [{ "sku_id": "prod_123", "quantity": 2 }]
    },
    "customer": {
      "customer_id": "cust_demo",
      "segments": ["vip"],
      "total_orders": 5,
      "per_customer_used": {}
    }
  }'
```

## Response (200)

```json
{
  "coupons": [
    {
      "offer": {
        "_id": "offer_123456_abc",
        "code": "FLAT50",
        "title": "Flat ₹50 off",
        "discount": { "type": "flat", "value": 50 }
      },
      "is_eligible": true
    }
  ],
  "auto_offers": [
    {
      "offer": {
        "_id": "offer_auto_001",
        "title": "VIP Early Access",
        "discount": { "type": "percentage", "value": 10 }
      },
      "is_eligible": true
    }
  ]
}
```

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Invalid cart or customer data |

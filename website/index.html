// Features

Everything you need to run offers

From simple flat discounts to complex stacking rules — OfferForge handles it all.

Coupon Codes

Flat or percentage discounts with codes like FLAT50, SAVE10. Min cart values, max caps, per-customer limits.

Auto-Applied Offers

Show offers automatically based on cart contents. No code needed. "10% off Electronics" when cart has electronics.

13 Rule Types

Min cart value, customer segment, first-time buyer, weekend only, category restriction, product combo, and more.

Stacking & Conflicts

Define how offers combine. The engine resolves conflicts using priority, exclusive flags, and global policies.

Analytics

Track redemptions, conversions, abandonment. Measure AOV lift and revenue impact per offer.

Team & Roles

Invite team members with role-based access. Owner, admin, offer manager, analytics viewer.
